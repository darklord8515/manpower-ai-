# SmartHR screen reference

Source: `smarthr.dreamstechnologies.com/smarthr.dreamstechnologies.com/hrm/html/`. All pages use the SmartHR admin shell (sidebar + top bar, page title/actions, main content); the notes below describe each page’s content layout. “Cards” names the visible metric/content panels; table headers are listed in order.

| Screen(s) | Layout, cards and table columns |
|---|---|
| **Dashboards** | **dashboard / index / layout-horizontal:** dashboard header, KPI tiles, charts and task list; table: ID, Name, Team, Hours, Priority. **employee-dashboard:** personal KPI tiles, attendance/leave/task panels. **hr-dashboard:** KPI overview, employee/leave distribution and attendance trend charts. **attendance-dashboard:** overview stats, attendance trend/status and office-vs-remote charts. **asset-dashboard:** asset KPI tiles and asset table: Asset ID, Asset Name, Assigned To, Purchase Date, Warranty Expiry, Status, Action. **finance-dashboard:** finance KPIs, payroll growth chart, transactions: Transaction ID, Employee, Category, Amount, Date, Status. **payroll-dashboard:** payroll summary, batch status, tax/deduction trend. **recruitment-dashboard:** recruitment KPIs/charts and job list: Job ID, Date, Job Title, Location (plus department funnel: Department, Applicants, Shortlisted, Interviewed, Offered, Hired). **help-desk-dashboard:** ticket KPI tiles and support overview. **it-admin-dashboard:** service health/status KPI tiles and system panels. **leads-dashboard:** funnel/KPIs and leads table: Company Name, Stage, Created Date, Lead Owner. **deals-dashboard:** deal KPIs/charts and table: Deal Name, Stage, Deal Value, Owner, Closed Date. |
| **AI insights** | **ai-attendance-insights:** attendance overview, trend/exception insight cards and charts. **ai-hiring-forecast:** hiring timeline, hiring statistics and pipeline cards; table: Role, Department, Urgency, Openings, Pipeline Fill. **ai-payroll-forecast:** forecast KPI cards and payroll trend/breakdown charts. **ai-team-performance-insights:** performance, hiring prediction, productivity/quality and collaboration insight panels. **ai-configuration:** settings/permissions matrix; columns: User, AI Config, Model Settings, Data Training, API Access, Module Permissions, Read, Write, Create, Delete, Import, Export. |
| **People & work lists** | **activity:** activity list; Title, Activity Type, Due Date, Owner, Created Date. **todo:** task list with filters/status. **calendar:** month/week calendar grid with event details. **kanban-view:** stage columns with draggable record cards. **agents:** agent roster; Agent ID, Agent Name, Email, Role, Tickets Assigned, Tickets Resolved, Availability. **tickets:** searchable support-ticket list with status/priority and detail view. **escalation-rules:** rules table; Rule ID, Trigger Type, Priority, Condition, Escalation Level, Escalates To, Time Threshold, Status. **sla-policies:** policy table; Priority, Description, First Response Time, Resolution Time, Escalation Time, Escalates To. |
| **CRM** | **companies:** searchable company table; Company Name, Email, Account URL, Plan, Created Date, Status. **companies-grid:** company cards/grid. **contacts:** contacts table; Name, Email, Phone, Location, Rating, Owner, Contact, Status. **leads-grid:** lead cards/grid with stage and owner. **deals-grid:** deal cards/grid with stage/value. **pipeline:** pipeline list; Pipeline Name, Total Deal Value, No. of Deals, Stages, Created Date, Status. |
| **Billing & tenant admin** | **packages:** plan table; Plan Name, Plan Type, Total Subscribers, Price, Created Date, Status. **subscription:** subscriber table; Subscriber, Plan, Billing Cycle, Payment Method, Amount, Created Date, Expiring On, Status. **invoices:** invoice table; Invoice, Name, Created On, Total, Amount Due, Due Date, Status. **purchase-transaction:** transaction table; Invoice ID, Customer, Email, Created Date, Amount, Payment Method, Status, Plan, Billing Cycle. **domain:** tenant domain table; Name, Domain URL, Plan, Created Date, Status. **tenant-usage-metrics:** tenant usage table; Tenants, Plan, Active Users, Most Module Usage, Storage Usage, Status. **tenant-support-tickets:** support KPI cards and ticket queue. |
| **Communication & settings** | **chat:** conversation list + message thread. **email:** mailbox folders, message list and reading pane. **notes:** notes list/cards with editor/detail. **file-manager:** folder/file browser; Name, Size, Type, Modified, Share. **profile-settings:** settings navigation with profile/account preference forms. **call-history:** call log; Name, Phone, Call Type, Duration, Date & Time. **incoming-call / outgoing-call / voice-call / video-call:** full-screen call state, caller/participant details and call controls; video-call includes participant video tiles. |
